PRZYPADKI DO EVALUATION SETU: Northstar DEVELOPMENT
W Studio Web: agent SupportAgent → Evaluations → evaluation set "Northstar DEVELOPMENT" → dla każdego zgłoszenia dodaj przypadek i wklej Input, Expected output i Expected agent behavior.
Plik jest generowany z dane/zgloszenia.json i testy/oczekiwane_wyniki.json (narzedzia_pakietu/make_tables.py).

============================================================
REQ-001
============================================================
Input:
{
  "requestId": "REQ-001",
  "requesterEmail": "anna@example.com",
  "subject": "Eksport sprzedaży",
  "body": "Od wczoraj eksport raportu sprzedaży kończy się błędem 500. Wybrałam okres ostatnich 60 dni. Potrzebuję go na spotkanie.",
  "service": "sales"
}

Expected output:
{
  "requestId": "REQ-001",
  "category": "INCIDENT",
  "nextAction": "DRAFT_REPLY",
  "humanReview": false,
  "matchedIssueId": "KI-001"
}

Expected agent behavior:
Agent wywołuje FindKnownIssue, najwyżej raz. Nie wywołuje GetServiceStatus ani GetTicketStatus. Może sięgnąć do wiedzy Northstar_KB.
